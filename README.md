# 나만의 TEF 트레이너

TEF Canada 프랑스어 공부를 위한 개인 학습 트레이너입니다. 별도 서버 없이 브라우저에서 바로 동작하는 정적 사이트로, 폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## ▶ 바로 열기

- **깃헙 버전 (이 리포, 현재 버전 28)**: [sidebatch.github.io/tef-trainer](https://sidebatch.github.io/tef-trainer/)
- **뮤즈 링크 버전**: [muse.ai/s/tef-2](https://muse.ai/s/tef-2-xzxs5xxpkqxwxrin)

두 버전의 콘텐츠는 같습니다. 진도는 버전·기기별로 따로 저장됩니다.

## 기능

- **오늘**: 공부 순서(읽기 연습 → 듣기 CO-A → 듣기 연습 → 읽기 모의고사 → 듣기 모의고사 → 미채점 연습)대로 다음에 풀 문항을 바로 이어서 열 수 있고, 모의고사 CO-B 세트 1~5와 CO-C 세트 1·3·4·5(CO-C 세트 2는 모의고사 CO 2-A의 9~14번으로 연결되는 바로가기 행 포함) 바로가기, 공부 달력(실제로 공부한 날의 문항 수 · 단어 수 기록)을 제공합니다.
- **읽기 (CE)**: 연습 세트 9개 + 모의고사 4개, 총 187문항. CE-B 모의고사 (1)(2)·(3)(4)는 원본 자료와 동일하게 각 12문항입니다. 문장별 해석 열기, 보기별 해석 토글, 채점 피드백과 해설, 문항 단어 저장, 섹션별 읽기 전략 8개를 제공합니다. CE-C 43문항에는 파일럿으로, 답을 고른 뒤 복습에서 여는 문장 뜯어보기(청크 단위 직독직해)와 문장 타이핑 연습(한국어 뜻을 보고 문장 전체를 직접 타이핑, 빈칸 문장은 정답 단어를 채운 문장이 목표)이 붙어 있습니다.
- **듣기 (CO)**: 163문항 (채점 156 · 미채점 7). 채점 문항은 답을 고르기 전 1회만 재생할 수 있는 시험 모드를 지키고, 답을 고른 뒤에는 대본 문장별 복습, 딕테이션(구두점은 빼고 단어만 비교), 쉐도잉(전체 보기 · 앞부분만 · 가리기)을 제공합니다. 듣기 파일 재생 중 반복 듣기를 켜면 끝나자마자 처음부터 다시 재생됩니다. 음성인식 대본 문항은 배지와 안내 문구를 함께 보여줍니다. 근거 자료가 없는 미채점 세트는 채점 없이 선택만 저장합니다.
- **표현 (EE/EO)**: 쓰기 편지 모델 틀과 완성 예시, 쓰기 전략, 패턴 드릴 10개(모델 보기 → 조립 → 한 칸 바꾸기 → 가리고 다시 쓰기), 말하기 전화 문의 스크립트 트레이너(도입 조립 · 카테고리 질문 8개 · 반응 문장 · 결론), 포스터 연습 40개를 제공합니다.
- **단어**: 핵심 단어 24장, CO 어휘 184장(섹션별) 플래시카드와 3단계 표시(아직 낯설어요 · 헷갈려요 · 이제 익숙해요), 문항에서 모은 내 단어, 검색 가능한 관용표현 305개, EE/EO 필터가 있는 Sujet 137개를 제공합니다.
- **발음**: 프랑스어 문장마다 듣기 버튼이 붙어 있습니다. 미리 만들어 둔 음성 파일이 있으면 그 파일을 재생하고, 없으면 기기의 프랑스어 음성으로 읽어 줍니다.

## 앱 동작

- **뒤로가기**: 폰의 뒤로가기 버튼·제스처가 앱 안에서 한 단계씩 돌아갑니다. 맨 첫 화면에서만 앱을 나갑니다.
- **자동 업데이트**: 새 버전이 나오면 앱으로 돌아올 때 확인해서 자동으로 갈아탑니다. 오늘 화면 맨 아래에 현재 버전이 표시됩니다.
- **진도 저장**: 진도는 브라우저의 `localStorage`(`tef-trainer-v1` 키)에만 저장됩니다. 기기마다 진도가 따로 쌓이는 것이 의도된 동작입니다. 사이트 데이터를 지우면 진도도 지워지니 주의하세요.

## 데이터 출처

- `data/*.json`은 `~/workspace/tef-personal-app/`에 단계적으로 정리된 JSON에서 가져왔습니다.
- 문항, 대본, 모델 문장 등은 과외 선생님 자료를 바탕으로 한 개인 공부용 자료입니다.

## 기술

- 정적 사이트: `index.html` + `styles.css` + `app.js` (바닐라 JS, 빌드 과정과 외부 CDN 없음)
- PWA: `manifest.webmanifest` + 네트워크 우선(network-first) 서비스 워커 `sw.js`. 듣기 음성 파일은 서비스 워커가 미리 저장하지 않습니다.
- 수정 뒤에는 `tests/run-tests.js` 검사가 전부 통과해야 배포합니다. 버전 표기(오늘 화면 · 셸 · 서비스 워커 · 이 문서)가 서로 어긋나면 검사에서 실패합니다.

## 배포

GitHub Pages로 `main` 브랜치 루트에서 배포합니다. 파일을 수정해 푸시하면 그대로 반영됩니다.
